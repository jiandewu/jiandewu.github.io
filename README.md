# jiandewu.github.io

Source for https://jiande.is-a.si: static HTML and CSS with no build step.

- `index.html`: English home page; `zh/index.html`: Chinese page.
- `Jiande_Wu_CV.pdf`: public CV, built from a Markdown source kept elsewhere.
- `/ai-frontier-digest/` is served from the [ai-frontier-digest](https://github.com/jiandewu/ai-frontier-digest) repository's own GitHub Pages site and reuses `style.css`.
